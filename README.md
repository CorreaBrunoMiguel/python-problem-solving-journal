# Python Problem Solving Journal

Jornada de aprofundamento técnico em Python iniciada em 11/09/2026.

## Propósito

Desenvolver e demonstrar raciocínio lógico, resolução de problemas,
domínio de Python e capacidade de justificar decisões de implementação.

## Metodologia

Os desafios são realizados progressivamente, com interpretação de
requisitos, implementação, verificação e revisão.

O raciocínio e as implementações são de autoria do aluno. A IA atua
como mentora técnica; intervenções relevantes e soluções fornecidas
serão identificadas nos registros dos exercícios.

## Organização

Cada desafio terá sua própria pasta em:

`exercises/AAAA/MM/NNN-nome-do-desafio/`

A numeração será contínua, sem reinício mensal. As pastas serão
criadas conforme os desafios forem iniciados.

## Execução

A versão do Python e as instruções de execução e verificação serão
registradas conforme os primeiros exercícios forem implementados.
